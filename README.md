# Elite Developments 

Homepage concept for [elitedevelopments.ca](https://elitedevelopments.ca/), inspired by the editorial style of Ballymore.

## Structure

```
index.html
assets/
  css/style.css     Styles (Jost + Source Serif 4, Elite teal and gold)
  js/main.js        Header, mobile menu, hero video control, reveals, counters, development filter, portfolio slider
  images/           Logos, hero film loop and poster, development (dev/) and portfolio (port/) photos from the client site
  fonts/            Self-hosted woff2 fonts
```

The hero film is a 15 second loop cut from the client's site video, using only scenes without burned-in text.
